Help & Getting Started

How Stitch Math reads a pattern, and what to do when it disagrees with you.

1. Write or paste your pattern

Go to Studio and paste the whole pattern into the big box, one row on each line. Write it the normal way:

Row 1: ch 13, sc in 2nd ch from hook and in each ch across (12)
Row 2: ch 1, turn, [sc in next st, inc in next st] x 6 (18)

End each line with the stitch count in brackets, like (18). That is the number Stitch Math checks its own arithmetic against.

Press Validate Entire Pattern when you are ready.

2. Ways to write a row
  • Repeats. [sc, inc] x 6 works the bracketed group six times.
  • Several rows at once. Rows 2-6: sc in each st across counts all five.
  • New piece. A line on its own like SLEEVE starts a new section, and row numbers begin again.
  • Sizes. ch 41 (45, 49) is read as three sizes. Stitch Math notices and offers a size picker.
  • Notes. Lines that make no fabric — assembly, reminders — are shown but not counted.
3. Read the results

The Pattern Validation Matrix gives every row a line. Calc Total is what Stitch Math counted; User Total is what you wrote.

  • Green — the row adds up.
  • Red — the row cannot be worked as written. The reason is in the last column.
  • Gray — not checked, because an earlier row has to be fixed first.

Use Jump to First Error to go straight to the first problem. If a count disagrees, Stitch Math treats its own arithmetic as correct and tells you so — it never edits your pattern.

4. Gauge and how much yarn

In Gauge Profile, enter your swatch: how many stitches and rows, over what size square. Press Calculate Gauge.

Add the skein weight and length from the yarn label, then Calculate Yardage for an estimate of how much you need.

Washed or blocked your swatch? Put those counts in as well — the finished garment has the washed gauge, so those win.

5. Grade it to other sizes

Sizer / Grader turns one size into a range. Give it the size the pattern was written for, pick a size chart, and it works out the rest.

Ease is never assumed. Give any two of body, finished and ease, and the third is worked out and labeled as derived.

Every measurement on the schematic is clickable, and shows the full working behind its stitch count.

6. Terms Stitch Math does not know

If your pattern uses a stitch it cannot count, add it in Library: how many stitches it uses and how many it makes.

Colorwork like With A, ch 146 works without any setup. Adding the colors just puts names to the letters.

Custom stitches last as long as the page does — a term defined for one pattern is not carried into the next.

7. Save, print and export
  • Patterns — name a project and Save File. It stays in this browser.
  • Save as Text — your pattern with the counts corrected.
  • Save as PDF — the pattern as a PDF file, with the metadata and stitch table.
  • Publish / Export — generated multi-size instructions once a pattern is graded.

Everything is stored in this browser only. Clearing your browser data removes your saved projects, so export anything you want to keep.

About Stitch Math

Your work never leaves this device. Patterns, gauge history, your stitch dictionary and your testers’ measurements are stored in this browser and nowhere else. Stitch Math has no account, no server and makes no network requests. The only way anything leaves is when you export it yourself.

Tester Notes

Pattern Input

Paste the whole pattern, one row per line. End each line with the total stitch count in parentheses, e.g. [sc, inc] x 3 (9). Start a new piece with a title line such as SLEEVE. Specifications, abbreviation lists and pattern notes can be left in — they are shown as notes, never validated, and the hook, yarn, gauge and skill level are read from them.

How to title a new piece

A title line tells Stitch Math one piece has ended and another has begun. It is the one thing worth getting right by hand, because a title restarts the stitch count at zero.

Write a title one of these four ways. Anything else is read as an ordinary note, which is usually what you want:

  • All capitals — SLEEVE
  • Ending in a colon — Sleeve:
  • Between dashes — --- Sleeve ---
  • With a make count — Sleeves (Make 2)

Only title a piece that starts its own fabric. A sleeve worked separately is a new piece. Ribbing at the hem, or a body carrying on from the yoke, is not — it continues the stitches above it, so leave headings like Sweater Body or Body Bottom Ribbing as plain text and the count carries straight through. Title one of those and its first row will fail for want of stitches that are really there.

Name the stitches you set aside. If a piece is worked into stitches an earlier row held back, say so by name — skip 38 sts (Right Sleeve), or a breakdown line such as (Back = 48 hdc, Right Sleeve = 38 hdc). Title the piece Sleeves and those 38 stitches are carried across to it instead of the piece starting from nothing.
